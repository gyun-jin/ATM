# ATM

## 프로젝트 소개

C++ 객체지향 프로그래밍을 활용해 구현한 콘솔 기반 ATM 프로그램입니다.

계좌 생성, 잔액 조회, 입금, 출금, 계좌 이체, 관리자 통계 기능을 클래스로 분리하여 구현했습니다. 배열 기반 계좌 관리와 객체 간 역할 분리를 학습하기 위한 프로젝트입니다.

## 주요 기능

- 계좌 생성
- 계좌 잔액 조회
- 입금
- 출금
- 계좌 이체
- 관리자 모드
- 전체 계좌 잔액 합계/평균/최댓값 조회
- 계좌 정보 정렬 및 통계 출력

## 기술 스택

- C++
- Visual Studio
- 객체지향 프로그래밍
- 클래스와 객체
- 동적 배열
- 생성자와 소멸자

## 객체지향 설계

### ATMachine

ATM 프로그램의 전체 흐름을 관리합니다.

- 메뉴 출력
- 계좌 생성/조회/입금/출금/이체 기능 호출
- 관리자 모드 진입
- ATM 보유 금액 관리

### Account

계좌 정보를 관리합니다.

- 계좌 번호
- 계좌 비밀번호
- 예금주 이름
- 계좌 잔액
- 인증 처리
- 입금/출금 처리

### Statistics

계좌 통계를 계산합니다.

- 전체 계좌 잔액 합계
- 평균 잔액
- 최대 잔액
- 계좌 정렬

## 실행 방법

1. Visual Studio를 실행합니다.
2. `PYJ_ATM2.sln` 파일을 엽니다.
3. 프로젝트를 빌드합니다.
4. 디버깅을 시작하여 콘솔 프로그램을 실행합니다.
5. 화면에 표시되는 메뉴 번호를 입력하여 기능을 이용합니다.

## 학습 포인트
